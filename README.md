Базовое RAG-ядро ИИ-ассистента (c алгоритмом FAISS и подключением реранкера, добавалением ВМ25). 

В оригинальной задумке ИИ-ассистент должен был ответить на 500 вопросов (заданы в questions.csv), найти ответы на которые надо в 350 финансовых статьях из train_data.csv, выводя ответы в файл submission.csv.

FAISS сортирует статьи из train_data.csv по (логика прописана в rag_core.py), находя релевантные источники информации и возвращая top_k документов реранкеру на анализ (по умолчанию отключено в пользу BM25, чтобы не тратить квоту).

В качествае модели был отобран mistral-small-3.2-24b-instruct - легко промпить, довольно умная
В качестве реранкера был отобран text_embedding_3_small
В качестве реранкера был взят Qwen3-Reranker-4B (один API-ключ с эмбеддером)

Файл libraries.txt - список всех библиотек, разрешенных на закатоне.
requirements.txt - список всех использованных.
