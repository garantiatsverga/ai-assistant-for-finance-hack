# AI-ассистент для ответов на финансовые вопросы

## 🏆 Диплом хакатона

![Certificate](certificate.jpg)

---

Реализация **Retrieval-Augmented Generation (RAG)** системы для поиска ответов на вопросы в финансовых документах с использованием гибридного подхода (FAISS + BM25).

## Описание проекта

ИИ-ассистент предназначен для ответа на финансовые вопросы путём поиска релевантной информации в корпусе документов. Система обрабатывает 500 вопросов и ищет ответы в 350+ финансовых статьях.

### Архитектура

```
Вопрос → Embedding → FAISS/BM25 Search → Reranking → LLM → Ответ
```

- **Retrieval**: FAISS индекс для быстрого поиска релевантных документов
- **Ranking**: BM25 и дополнительный реранкер для улучшения релевантности
- **Generation**: LLM для синтеза финального ответа на основе найденных источников

## Компоненты

| Модуль | Описание |
|--------|---------|
| `rag_core.py` | Основное RAG-ядро с логикой поиска и обработки документов |
| `embedding_service.py` | Управление эмбеддингами и индексацией документов |
| `llm_service.py` | Интеграция с LLM для генерации ответов |
| `full_text_search.py` | BM25 текстовый поиск |
| `main.py` | Точка входа приложения |

## Используемые модели

- **LLM**: `mistral-small-3.2-24b-instruct` — производительная и простая в промпт-инжиниринге модель
- **Embedding модель**: `text_embedding_3_small` — компактное представление текста
- **Reranker**: `Qwen3-Reranker-4B` — быстрое переупорядочение кандидатов

## Требования

Проект использует зависимости из `requirements.txt`, включая:
- FAISS для семантического поиска
- LangChain экосистему для orchestration
- PyTorch и Transformers для работы с моделями

## Используемые библиотеки

Все используемые библиотеки перечислены в `libraries.txt` и соответствуют регламенту хакатона.

## Важные замечания

- **Конфиденциальность данных**: Организаторы хакатона просят не выкладывать материалы в открытый доступ (например, на Hugging Face), так как они предназначены только для локального использования и экспериментов.

## Запуск
