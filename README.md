Базовое RAG-ядро ИИ-ассистента. 

В оригинальной задумке ИИ-ассистент должен был ответить на 500 вопросов (заданы в questions.csv), найти ответы на которые надо в 350 финансовых статьях из train_data.csv, выводя ответы в файл submission.csv.

Алгоритм сортирует статьи из train_data.csv по косинусному сходству (логика прописана в rag_core.py), находя релевантные источники информации. Если нет сходств, возвращает: "В базе знаний нет релевантной информации для ответа на этот вопрос."

В первой версии (и нескольких следующих) мы получали много таких проблем.


Файл libraries.txt - список всех библиотек, разрешенных на закатоне.
requirements.txt - список всех использованных.
